# Introducción y objetivos

## Introducción
En el contexto académico actual, la correcta presentación de trabajos escritos es fundamental para garantizar la claridad, coherencia y validez de la información. El uso de normas estandarizadas, como las Normas APA (7.ª edición), permite organizar adecuadamente las ideas y dar el debido crédito a las fuentes consultadas.

Asimismo, el desarrollo de este manual de buenas prácticas responde a la necesidad de integrar herramientas digitales, como GitHub, en la gestión y presentación de contenidos académicos. Esto no solo facilita la organización de la información, sino que también promueve habilidades digitales relevantes en entornos profesionales.

## Objetivos

### Objetivo general
Desarrollar un manual de buenas prácticas que integre el uso de Normas APA (7.ª edición) y herramientas digitales como GitHub para la correcta elaboración y presentación de trabajos académicos.

### Objetivos específicos
- Explicar los principios fundamentales de las Normas APA (7.ª edición).
- Describir los formatos adecuados de presentación de trabajos académicos.
- Aplicar GitHub como herramienta para la organización y publicación del contenido.
- Fomentar buenas prácticas en la redacción académica y gestión de información.
