# Herramientas Colaborativas para el Trabajo Universitario

Para este diplomado, hemos identificado las siguientes herramientas clave:

## 1. Trello
* **Uso:** Gestión de tareas mediante tableros Kanban.
* **Ventaja:** Permite ver el progreso visual de cada integrante.

## 2. Google Docs
* **Uso:** Redacción simultánea de documentos.
* **Ventaja:** Historial de versiones y comentarios en tiempo real.

## 3. GitHub (Nuestra elección principal)
* **Uso:** Control de versiones profesional.
