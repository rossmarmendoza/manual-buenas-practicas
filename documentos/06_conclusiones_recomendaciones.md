# 📌 Conclusiones y recomendaciones

## Conclusiones
El desarrollo de este manual de buenas prácticas permitió integrar conocimientos sobre Normas APA (7.ª edición), formatos de presentación y herramientas digitales colaborativas. Asimismo, se evidenció la importancia de la organización, la planificación y el uso adecuado de recursos tecnológicos en la elaboración de trabajos académicos.

El uso de plataformas como GitHub facilitó la gestión del contenido, promoviendo el trabajo en equipo y el control de versiones, lo cual resulta relevante en entornos académicos y profesionales.

## Recomendaciones
Para futuros estudiantes, se recomienda:

- Aplicar correctamente las Normas APA para garantizar la calidad académica.
- Utilizar herramientas colaborativas para mejorar la comunicación y organización del equipo.
- Implementar técnicas de gestión del tiempo, como la Técnica Pomodoro.
- Planificar las actividades mediante cronogramas realistas.
- Aprovechar plataformas como GitHub para documentar y estructurar proyectos.

## Reflexión final
El uso de buenas prácticas académicas y herramientas digitales no solo mejora la presentación de los trabajos, sino que también desarrolla competencias clave para el ámbito profesional, como la organización, la responsabilidad y el trabajo colaborativo.
