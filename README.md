## Integrantes

- Gabriela Nava

## Descripción
Este proyecto consiste en la elaboración de un manual de buenas prácticas académicas, enfocado en la correcta aplicación de las Normas APA (7.ª edición), formatos de presentación y el uso de herramientas digitales colaborativas. 

El manual también incluye estrategias de gestión del tiempo, con el objetivo de mejorar la organización, la productividad y la calidad en la elaboración de trabajos académicos. Asimismo, se integra el uso de GitHub como plataforma para la gestión y estructuración del contenido.

## Guía de uso
Para acceder al contenido completo del manual, dirígete a la carpeta:

📂 `/documentos`

En esta sección encontrarás los archivos organizados por temas, donde se desarrolla de manera detallada cada aspecto relacionado con las buenas prácticas académicas.

## Objetivo del proyecto
Proporcionar una guía clara y estructurada que permita a los estudiantes mejorar la elaboración de trabajos académicos, aplicando normas estandarizadas y herramientas digitales de apoyo.

## Tecnologías utilizadas
- Markdown
- GitHub
- Herramientas colaborativas (Trello, Google Docs)
